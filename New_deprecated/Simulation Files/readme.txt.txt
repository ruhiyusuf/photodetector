This folder contains the simulation files that can be used to analyze the theoretical behavior of the circuit.
It is recommended to use Ltspice for simulation. But any other spice software should also work.

Ltspice is available on Windows CAEN. The file named "ideal" contains the circuit.

Remember to add the components to the library path. As the circuit uses custom components that are not predefined
in the built-in library of Ltspice.
